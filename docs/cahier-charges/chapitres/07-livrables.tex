\begin{tableau}{L{4cm} Y}
  \entete{Livrable} & \entete{Contenu} \\
  \midrule
  Dépôt Git & Code source complet et historique des commits, branches et pull requests \\
  \midrule
  README & Présentation, captures, installation, compilation, lancement des tests, architecture, sources et licences \\

  Soutenance & 30 minutes, démonstration comprise \\

La démonstration suit le parcours d'un utilisateur : premier lancement, carte
du jour, fiche recette, mode cuisine, accords, composition d'un menu, liste de
courses, puis passage hors ligne. Le reste de la soutenance présente
l'architecture, les choix techniques et les tests.
